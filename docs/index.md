# ALBATROS Analysis

Documentation for the ALBATROS data analysis and satellite calibration pipeline, as written by Thomas and Mohan. A general overview of the setup is found on this page, and a full in-depth explanation is found in the [Pipeline](Pipeline.md) section. 

## Overview

This package contains tools for processing, calibrating, and analyzing radio interferometric data. The project is organized into two main components:

- **Core API (`src`)**  
  Reusable Python modules containing the main analysis algorithms, calibration routines, data processing tools, and utilities. Access: [API](api/index.html)

- **Scripts (`scripts`)**  
  Standalone programs used to run analysis pipelines, generate results, and perform specific processing tasks. Access: [Scripts](scripts/index.html)
