This API documentation details all re-usable functions used in the albatros_analysis pipeline. These encompass a large range of uses, such as data iteration, satellite position predictions, and least squares objective functions. The code is split into two main sections.

## Utils
These detail typical functions, and are split by their uses. For example, pfb_utils will be things used for the re-pfb pipeline, whereas fine_timing_utils will mainly be used for the fine timing data analysis section.
